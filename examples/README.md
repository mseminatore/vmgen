# VMGen Examples

This directory contains sample assembly programs for VMs generated by VMGen.

## Quick Start

### 1. Generate a VM from a spec

```bash
# Generate the minimal VM
./vmgen specs/minimal.yaml -o gen_minimal/

# Or the full-featured VM
./vmgen specs/full.yaml -o gen_full/
```

### 2. Build the generated VM

```bash
cd gen_minimal
mkdir build && cd build
cmake ..
cmake --build . --config Debug
```

### 3. Use the assembler in your program

The generated assembler converts text assembly into bytecode:

```c
#include "assembler.h"
#include "vm.h"

int main(void) {
    // Set up constants
    minimal_vm_t vm;
    minimal_vm_init(&vm);
    minimal_vm_add_constant(&vm, 10);   // constant[0] = 10
    minimal_vm_add_constant(&vm, 32);   // constant[1] = 32

    // Assemble the program
    minimal_assembler_t as;
    minimal_asm_init(&as);
    minimal_asm_assemble(&as,
        "PUSH_CONST 0\n"
        "PUSH_CONST 1\n"
        "ADD\n"
        "HALT\n"
    );

    // Run
    int rc = minimal_vm_run(&vm, as.code, as.len);
    printf("Result: %lld\n", (long long)vm.stack[0]);  // 42

    return rc;
}
```

## Assembly Syntax

- One instruction per line
- Mnemonic followed by space-separated operands
- Comments start with `;` or `#`
- Empty lines are ignored

```asm
; This is a comment
PUSH_CONST 0    ; push constant at index 0
ADD             ; pop two values, push sum
HALT            ; stop execution
```

## Available Instructions

Instructions depend on your spec. Common ones:

| Instruction | Operands | Description |
|------------|----------|-------------|
| `PUSH_CONST` | `index` (uint16) | Push constant onto stack |
| `POP` | — | Pop top of stack |
| `ADD` | — | Pop two, push sum |
| `SUB` | — | Pop two, push difference |
| `MUL` | — | Pop two, push product |
| `DIV` | — | Pop two, push quotient |
| `EQ` | — | Pop two, push 1 if equal, 0 otherwise |
| `LT` | — | Pop two, push 1 if a < b |
| `JUMP` | `offset` (int16) | Relative jump |
| `JUMP_IF_FALSE` | `offset` (int16) | Jump if top of stack is zero |
| `CALL` | `func_index` (uint16), `arity` (uint8) | Call function |
| `RETURN` | — | Return from function |
| `HALT` | — | Stop execution |
